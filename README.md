# Fibonacci Sequence Generator

## Project Description
This project contains a Python program that generates the Fibonacci sequence for a specified number of terms.

## Features
- Accepts the number of terms as input.
- Generates the sequence using a `for` loop.
- Displays the Fibonacci numbers.

## Requirements
- Python 3.x

## Installation
1. Download or clone this repository.
2. Ensure Python 3 is installed.

## Usage
Run the program using:

```bash
python fibonacci.py
```

Enter the number of terms when prompted.

## Example

**Input:**
```text
Enter the number of terms: 5
```

**Output:**
```text
0 1 1 2 3
```
